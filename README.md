# MLMeteo

App meteo Android in italiano, Material You, parte delle **MLapps**.

- 15 fonti gratuite selezionabili (ECMWF, ICON, ItaliaMeteo ARPAE, Météo-France, Met Office, GFS, YR.no e altre) più il **Consenso**
- Più località salvate, posizione GPS, campanella per la località delle allerte
- Radar: RainViewer (osservato) e **Mappa MLMeteo** di previsione calcolata con i dati ICON / ECMWF
- Temi dai colori dello sfondo, colore manuale, chiaro / scuro / AMOLED, 6 set di icone
- Home personalizzabile (elementi e ordine), pioggia in % o mm, unità di misura
- Aggiornamenti in app dalle Release di GitHub

L'APK viene compilato da GitHub Actions e pubblicato nelle **Release**.
